## Questions and bug reports

- Use **Issues** for reproducible bugs, data corrections and feature
  requests. The issue forms ask for the app version and data build id.
- For a wrong statistic, include the country, indicator, value, source year and
  the upstream URL.
- Check whether the value is also wrong at the upstream source; if so, it is an
  upstream report rather than a bug in this app.

## Security

Do not open a public issue for security problems. Follow
[SECURITY.md](SECURITY.md) and use the repository's **Security → Report a
vulnerability** tab.

## Conduct

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).

## What this project cannot help with

- Statistical advice beyond the documented methods (the app is not a
  peer-reviewed statistical package).
- Recovering missing upstream data.
- Redistributing commercially licensed indices (for example the EIU Democracy
  Index).
- Signed installers or macOS/Linux packages; only the Windows portable build is
  supported.
