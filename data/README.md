# The data folder

Everything in this folder is generated or local state. It is not committed to
git (see `.gitignore`). A release zip contains the generated snapshot so the
portable app works without a network.

## Layout

| Path | Generated by | Purpose |
| --- | --- | --- |
| `worlddata.sqlite` | `refresh_data.py` / `build_db.py` | Read-only analysis database |
| `manifest.json` | build | Schema version, build id, row counts, DB SHA-256, source snapshot metadata (online runs) |
| `quality_report.csv` | build | Per-indicator coverage, latest/median year, stale counts |
| `rejected.csv` | build | Values quarantined by range/non-finite checks |
| `unresolved.csv` | build (only when non-empty) | Source names that look like countries but could not be resolved |
| `skipped_entities.csv` | build (only when non-empty) | Aggregates and untracked territories |
| `raw/<source>/<date>/` | fetch | Immutable source snapshots with SHA-256 sidecars |
| `cache/` | build/tests | Scratch space |
| `settings.json` | app | Theme, cutoff, minimum N, last page, selections |
| `groups.local.yaml` | app | Local group membership overrides |

## Lifecycle

```powershell
# online refresh (reuses today's snapshots unless --force)
python scripts/refresh_data.py

# rebuild from existing snapshots, no network
python scripts/build_db.py

# verify manifest checksum + quality gates
python scripts/validate_data.py --strict

# import a manual index (writes raw/manual/<date>/<indicator>.csv and rebuilds)
python scripts/import_manual.py --indicator pisa_math --file pisa.csv
```

Within a calendar day an online run reuses the cached snapshot for each series.
Use `--force` to re-download. `--only` restricts the fetch to particular
sources or indicators and is intended for debugging, not for shipping a partial
database.

## Integrity

- The app verifies `manifest.json` and the SHA-256 of `worlddata.sqlite` at
  startup. Do not edit the database by hand.
- Rebuild from `raw/` if a file is damaged.
- Replace the database and manifest together; mismatches are refused.
- Close the app before replacing the database on Windows (the file is locked
  while open).

## Changing data

Do not edit generated files. Change the configuration instead:

- `config/indicators.yaml` — series, units, ranges, direction, aggregation
- `config/sources.yaml` — source licence/attribution
- `config/countries.yaml` — canonical entities
- `config/aliases.yaml` — source name mappings
- `config/groups.yaml` — group definitions

Then rebuild and run `python tools/gen_docs.py` so `docs/INDICATORS.md` and
`docs/GROUPS.md` stay in sync.
