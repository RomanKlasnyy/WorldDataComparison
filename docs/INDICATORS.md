# Indicator catalogue

> Data build: `20261125T185349Z` · generated 2026-11-25.

Coverage is the share of the **197 default states** with a value at or after the recency cutoff (default 2015). Territories are excluded from this denominator. Direction affects percentile bars and best/worst labels, not the correlation math. `log` means log10 is applied by default on the Correlations page. `composite` means the index is built from other indicators and may be tautologically correlated with its components.

## Manual imports

These indices are not downloaded or redistributed. Import a CSV/XLSX with `country` (or ISO3 code), `year` and `value` columns:

```powershell
python scripts/import_manual.py --indicator pisa_math --file pisa_math.csv
python scripts/import_manual.py --indicator freedom_house --file freedom_house.csv
python scripts/import_manual.py --indicator epi --file epi.csv
python scripts/import_manual.py --indicator nd_gain --file nd_gain.csv
python scripts/import_manual.py --indicator gpi --file gpi.csv
python scripts/import_manual.py --indicator social_progress --file social_progress.csv
```
